# 蜂鸟（Hummingbird）· 运行时默认与自启动

> 对应设计文档 v0.8 · 2026-11-09 编写
> ⚠️ 本文档先于软件编写，交付时逐条实测核对后转为正式版。

## 1. 交付物

**只有一个文件**：可执行二进制 `hummingbird`（musl 静态编译，arm64/armv7 按你的系统取一份）。
- Web 管理台（前端）已内嵌在二进制里，**没有独立的前端程序**，不存在第二个进程
- 无任何运行时依赖（不需要装 Node/Python/数据库）

## 2. 启动方式

```bash
./hummingbird              # 无参数 = 前台运行，Ctrl+C 停止
./hummingbird reset-password   # 唯一的附加子命令：重置 admin 密码（新密码打印在终端）
```

首次启动自动建库、建 admin 账号，**初始密码打印在 stdout**（只此一次，抄下来）。

## 3. 默认值一览

| 项 | 默认行为 | 怎么改 |
|---|---|---|
| **数据库** | `./hummingbird.db`——**相对启动时的工作目录**（在哪个目录运行，就在哪生成；WAL 模式，旁边会伴生 `-wal`/`-shm` 文件，属正常） | 环境变量 `HB_DB_PATH=/绝对路径/hummingbird.db` |
| **日志** | **stdout + stderr**。前台跑 = 直接打到终端；交给 systemd 跑 = 进 journald（见下） | 无法改文件——这是设计决定（进程不管日志落盘，交给运行环境） |
| **监听** | `0.0.0.0:8080`（全接口） | 环境变量 `HB_PORT=9090` |
| 初始账号 | `admin` / 首次启动 stdout 打印的随机密码，首次登录强制改密 | `reset-password` 子命令重置 |

### 关于"日志到底落在哪"

- **前台运行**：就在你的终端，重定向随意：`./hummingbird >> hb.log 2>&1`
- **systemd 运行**（推荐，见下节）：`journalctl -u hummingbird -f` 实时看；历史在 `journalctl -u hummingbird --since today`
- ⚠️ 树莓派 OS 默认 journal 是**易失的**（存内存 `/run/log/journal/`，重启清空）。想落盘持久化：`/etc/systemd/journald.conf` 里改 `Storage=persistent` 后 `sudo systemctl restart systemd-journald`，日志文件将落在 `/var/log/journal/`
- 推送/登录等**业务日志**在 Web 管理台里查（SQLite 存储，可设保留天数），与进程日志是两回事

## 4. 配置自启动（systemd）

**第一步**：把二进制放到固定位置并试跑一次（确认能起、抄下初始密码）：

```bash
sudo mkdir -p /opt/hummingbird
sudo cp hummingbird /opt/hummingbird/
cd /opt/hummingbird && sudo ./hummingbird     # 前台验证，Ctrl+C 退出
```

**第二步**：创建 unit 文件 `/etc/systemd/system/hummingbird.service`：

```ini
[Unit]
Description=Hummingbird message gateway
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
ExecStart=/opt/hummingbird/hummingbird
WorkingDirectory=/opt/hummingbird        # 数据库默认生成在这里（./hummingbird.db）
Restart=always
RestartSec=3
MemoryMax=64M                            # 内存兜底，符合设计预算
# Environment=HB_PORT=8080               # 需要时解开注释改端口
# Environment=HB_DB_PATH=/data/hb.db     # 需要时改库位置

[Install]
WantedBy=multi-user.target
```

**第三步**：启用并常驻：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now hummingbird   # 开机自启 + 立即启动
systemctl status hummingbird              # 确认 active (running)
```

**日常操作速查**：

```bash
sudo systemctl restart hummingbird   # 重启（升级后执行）
sudo systemctl stop hummingbird      # 停止
sudo systemctl disable hummingbird   # 取消开机自启
journalctl -u hummingbird -f         # 看日志
```

## 5. 升级 / 备份 / 卸载

```bash
# 升级 = 换文件 + 重启（数据不动）
sudo systemctl stop hummingbird
sudo cp 新的hummingbird /opt/hummingbird/hummingbird
sudo systemctl start hummingbird

# 备份/迁移 = 拷 .db（建议先停服务）
sudo systemctl stop hummingbird
sudo cp /opt/hummingbird/hummingbird.db ~/backup/
sudo systemctl start hummingbird

# 完整卸载
sudo systemctl disable --now hummingbird
sudo rm /etc/systemd/system/hummingbird.service && sudo systemctl daemon-reload
sudo rm -rf /opt/hummingbird
```
